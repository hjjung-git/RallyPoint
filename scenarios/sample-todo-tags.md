# 태그와 검색이 있는 할 일 CLI

## 목표
터미널에서 쓰는 할 일 관리 프로그램을 TypeScript로 만든다. 한 번에 다 만들지 않고 반복해서 키운다.
첫 반복에서는 할 일 추가(add), 목록 보기(list), 완료 처리(done)만 만들고, 데이터는 JSON 파일 하나에 저장한다.
그 결과를 확인한 뒤, 아래 완료 기준 중 아직 빠진 것을 다음 반복에서 채운다.

## 제약
- 외부 라이브러리 없이 Node.js 기본 기능만 쓴다.
- 명령마다 파일을 나누고, 저장소 읽기/쓰기 코드와 공용 타입은 여러 명령이 함께 쓰는 파일로 둔다.

## 완료 기준
- add, list, done 명령이 각각 별도 파일로 구현되어 있다.
- add 명령이 태그를 하나 이상 받을 수 있고, list 명령이 태그로 걸러 볼 수 있다.
- search 명령이 제목에 포함된 글자로 할 일을 찾는다.
- 저장소 읽기/쓰기와 검색 로직에 대한 테스트 파일이 있다(Node.js 기본 테스트 러너 사용).
- README에 모든 명령의 사용 예가 있다.
