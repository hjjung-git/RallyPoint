# 할 일 관리 CLI

## 목표
터미널에서 쓰는 작은 할 일 관리 프로그램을 TypeScript로 만든다.
할 일 추가(add), 목록 보기(list), 완료 처리(done) 명령을 지원하고, 데이터는 JSON 파일 하나에 저장한다.
사용법을 설명하는 짧은 README도 함께 만든다.

## 제약
- 외부 라이브러리 없이 Node.js 기본 기능만 쓴다.
- 명령마다 파일을 나누되, 저장소 읽기/쓰기 코드와 공용 타입은 여러 명령이 함께 쓰는 파일로 둔다.

## 완료 기준
- add, list, done 명령이 각각 별도 파일로 구현되어 있다.
- 공용 타입과 저장소 파일을 세 명령이 함께 사용한다.
- README에 세 명령의 사용 예가 있다.
